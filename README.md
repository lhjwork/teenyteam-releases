# Tinyfloor releases

Installers and update files for [Tinyfloor](https://tinyfloor-landing.vercel.app/), a small always-on panel that shows what your Claude Code subagents are doing (macOS and Windows).

This repository holds release files only. The app source is private. The free hook logger is at [lhjwork/tinyfloor-hooks](https://github.com/lhjwork/tinyfloor-hooks).

Tinyfloor is an independent project, not affiliated with Anthropic.
